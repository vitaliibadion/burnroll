# BurnRoll public pages

Apple requires HTTPS **Privacy Policy** and **Support** URLs. Email alone is not a Support URL.

This folder is the GitHub Pages site for [`vitaliibadion/burnroll`](https://github.com/vitaliibadion/burnroll).

## URLs

- Privacy Policy: `https://vitaliibadion.github.io/burnroll/privacy/`
- Support: `https://vitaliibadion.github.io/burnroll/support/`

## Publish

1. Push `main`, including this `docs/` folder.
2. On GitHub: **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main`, folder: `/docs`.
5. Wait until the site is live over HTTPS. Open both URLs in a browser before submitting the app.

Do not paste the URLs into App Store Connect until the pages load without a login.
